# UTIL-WPS-BackgroundGrid2
Displays grid and pointer position on PM desktop.

This program displays a grid on the PM desktop background, and shows the current mouse pointer position when the pointer is over the BGRID background window.  This is helpful in estimating or measuring sizes for windows, graphics, etc.

Double-click on the backround window to end it.
